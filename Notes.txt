Manual Setup & Usage

py -m pip install -U "yt-dlp[default]"

py -m yt_dlp "VIDEO_URL"

Issues?

Beware the audio may be not in the mp4 converted file so use the webm and convert that / extract mp3 audio from the webm file!


# A fix to try 

ffmpeg -i "video.mp4" -i "video.webm" -map 0:v:0 -map 1:a:0 -c:v copy -c:a aac -b:a 192k "video_fixed.mp4"

If you just want the sound as a separate MP3, run:
ffmpeg -i "video.webm" -vn -q:a 2 "audio.mp3"


The actual fix to prevent extra steps is simple install ffmpeg 1st
